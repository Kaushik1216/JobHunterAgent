JobHunterAgent: Features & Technical Sequence Architecture

An enterprise-grade autonomous job hunting and candidate-profile matching agent. Orchestrates real-time multi-portal scrapers, resilient HTML sanitizers, local SLM / cloud LLM inference engines with schema-guided self-correction, and an interactive React web dashboard.

Engine: Python 3.13 + FastAPI + uv
Inference: Ollama / LM Studio / OpenAI / Gemini / Claude
Database: SQLite (WAL Mode, Concurrency-Safe)
Resume Vault: Git-Ignored + SLM Parser (PDF / DOCX)
Frontend: React 18 + Vite + Tailwind CSS + Lucide
Integration: Model Context Protocol (FastMCP)

01. Multi-Portal Job Search & Discovery

Discovers job listings across LinkedIn, Indeed, and Company ATS Portals (Greenhouse, Lever, Workday) with rate-limiting and circuit breakers.

Discovery
Modules: src/portals/composite.py src/portals/linkedin.py src/portals/indeed.py src/portals/base.py
  • •
    Anti-Scraping Protection: Employs realistic browser user-agents, random jitter backoff, and localized session header simulation.
  • •
    Circuit Breaker Isolation: If a portal encounters consecutive 429/403 rate limits, the circuit breaker opens to isolate failure without halting other active portals.
  • •
    URL Normalization: Strips DuckDuckGo redirect wrappers (uddg=), converts localized LinkedIn slugs to canonical https://www.linkedin.com/jobs/view/{id}, and eliminates ATS tracking tokens.

03. Dual Pipeline Execution Modes

Enables decoupled operations: fast, zero-token "Search Only" discovery vs. offline batch "Match Only" AI evaluation vs. unified "Search & Match".

Orchestration
Modules: src/dashboard/run_manager.py src/agent/runner.py src/agent/pipeline.py models.enums.RunMode
  • •
    Mode 1 (Search Only): Scrapes portals, deduplicates against SQLite, downloads full JDs, and saves jobs as UNPROCESSED without consuming LLM tokens.
  • •
    Mode 2 (Match Only): Queries all pending UNPROCESSED jobs from the database and batches them through the LLM inference evaluator.
  • •
    Mode 3 (Search & Match): Executes end-to-end multi-portal discovery, immediate AI evaluation, threshold filtering, and status persistence.
Implementation Sequence: Run Manager Modes Mermaid Sequence Diagram

05. OutputGuard Schema Adherence & Retry Loop

Resilient parser that protects the pipeline from hallucinated or malformed LLM outputs with automatic feedback self-correction.

Inference
Modules: src/inference/output_guard.py pydantic.BaseModel exceptions.OutputValidationError
  • •
    Fenced Markdown Stripper: Automatically extracts embedded JSON from markdown code blocks (```json ... ```) or plain text.
  • •
    Self-Correcting Prompt Loop: If the model outputs broken JSON or violates schema constraints, OutputGuard sends the exact parsing error back to the model for an in-place fix (up to 2 retries).
  • •
    Adherence Rate Metric: Calculates and tracks real-time schema adherence rate across runs for observability.

13. Resume Profile & AI Extraction Engine

Local document ingestion with one-time SLM/LLM profile extraction, categorized skills taxonomy, and dynamic candidate-job matching injection.

Inference
Modules: src/agent/resume_parser.py src/dashboard/api.py (/api/resume/*) src/database/migrations/006_add_resumes.sql src/models/schemas.py (ParsedResumeProfile) src/agent/pipeline.py (_match_one) frontend/src/pages/ResumePage.tsx
  • •
    Local Git-Ignored Document Vault: Securely persists candidate resume files (PDF, DOCX, TXT, MD) inside the project's local resumes/ folder with UUID isolation. Guaranteed never to be tracked or committed to git via strict .gitignore rules.
  • •
    One-Time SLM/LLM Structured Extraction: Executes a single extraction pass upon upload. The configured local or cloud LLM analyzes raw document text and extracts candidate contact details, executive summary, calculated total YoE, categorized skills (Languages, Frameworks, Databases, Cloud/DevOps, Tools, Core Competencies), detailed work histories with technologies & quantifiable achievements, project portfolios, and inferred target roles.
  • •
    Permanent Zero-Token Caching: Parsed candidate profiles are serialized into the SQLite resumes table. Subsequent dashboard visits, card refreshes, and job matches read directly from SQLite without invoking further model tokens.
  • •
    Dynamic Candidate Matching Injection: When marked active, Pipeline._match_one() automatically overrides static criteria keywords with the candidate's real-world extracted skills and experience level, enabling personalized, autonomous job qualification scoring.
  • •
    Interactive Management & Re-Analysis: React-based UI features drag-and-drop file ingestion, multi-resume switching, active profile badges, an on-demand "Re-Analyze with AI" trigger (for testing newly loaded models), and a raw text inspector.
